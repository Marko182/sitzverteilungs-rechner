Auf GitHub Pages veröffentlichen

So machst du diesen Rechner kostenlos online erreichbar

  1. Code speichern: Speichere den gesamten HTML-Code als index.html auf deinem Computer.
  2. GitHub Repository: Erstelle ein neues Repository auf GitHub.com.
  3. Datei hochladen: Lade index.html über "Upload files" in den Root-Ordner hoch.
  4. Pages aktivieren: Gehe im Repository zu Settings → Pages → Wähle bei Source Deploy from a branch und Wähle Branch main / root.
  5. Fertig! Unter https://dein-username.github.io/repository-name ist die Seite nach ca. 1 Minute online.
